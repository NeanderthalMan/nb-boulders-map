Data sources
  • Boulder heatmap, hotspots, cliff faces: GeoNB 1 m lidar bare-earth DEM (GeoNB LidarProducts/DEM)
  • Cliff true angle: GeoNB lidar point clouds (LAZ), via the GeoNB lidar tile index
  • Masks for roads, rail, quarries, buildings, water: OpenStreetMap via the Overpass API (© OpenStreetMap contributors, ODbL)
  • Geology weight, granite-type bedrock: NBGS bedrock geology
  • Rock vs. sand/gravel cliffs: NBGS generalized surficial geology
  • Till sites, ice-direction calibration: NBGS till sample sites (2015+, 1986–2014)
  • Crown land: GNB Crown Lands
  • Base maps: GeoNB lidar hillshade, DSM hillshade and canopy height (GeoNB LidarProducts); Esri World Imagery and World Topo; OpenStreetMap tiles
  • My pins: owner's own field locations
NBGS = New Brunswick Geological Surveys; GeoNB / GNB = Government of New Brunswick. Hotspots and crags are model output, not surveyed features.
